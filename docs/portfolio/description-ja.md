# Pocket Booth

## ポートフォリオ用・短い紹介文

ビートの読み込みからボーカル録音、歌詞メモまで、iPhoneの縦画面で使える音楽制作Webアプリ。自分がラップを録る際の不便を起点に、実機で試しながら操作性と録音体験を改善しました。

## 詳細版

### 概要

Pocket Boothは、ビートに声を重ねる制作を、スマートフォンの縦画面で進められるWebアプリです。音声・動画ファイルからの音源読み込み、複数トラックへの録音、クリップの位置調整、歌詞メモ、WAV書き出しに対応しています。

### 開発の背景

自分でラップを制作する中で、「片手で扱いやすい縦画面で、ビートを流しながら声を録りたい」という課題がありました。必要な機能を絞って試作し、iPhoneで録音・再生を繰り返しながら、実際に使う際の問題を改善してきました。

### 主な機能

- 音声ファイルの読み込み、対応するMP4・MOVからの音声取り込み
- ビートを再生しながらのボーカル録音とマルチトラック再生
- 録音位置の補正、長押しによるクリップ移動
- 2本指でのタイムライン拡大・縮小
- トラックごとの音量・色・ミュート・ソロ設定
- プロジェクトごとの歌詞メモと端末内への自動保存
- ミックスの48kHz / 24bit WAV書き出し、プロジェクトのバックアップ
- 入力マイクの選択と、本体マイクを優先する処理（ブラウザが公開する入力の範囲内）

### 工夫した点

操作画面は録音とトラックに集中できるよう整理し、詳細設定は別画面にまとめました。再生位置の線を中央に固定し、周囲の波形が動く構成にしています。録音前にマイクと音声処理を準備することで、次の録音に入りやすくしました。

音声処理にはWeb Audio APIとAudioWorkletを使用しています。録音時刻と再生時刻の扱い、iOSの音声セッションの再初期化、入力チャンネルの位相による打ち消しなど、ブラウザ録音特有の問題にも対応を進めています。

### 開発の進め方・担当

個人制作として、課題の整理、機能・UIの方針決定、iPhoneでの実機確認、フィードバックに基づく優先順位付けを行いました。実装と検証には生成AIの支援も活用し、小さな改善を繰り返しています。

### 使用技術

HTML / CSS / JavaScript（ES Modules） / Web Audio API / AudioWorklet / MediaDevices API / IndexedDB / Web App Manifest / Node.jsによるテスト / Playwrightによるブラウザ検証

### 現在の状態

STUDIO 11時点の開発中プロトタイプです。iPhone Safari・ホーム画面追加での利用を中心に改善しています。音質、入力の切り替え、遅延は端末・ブラウザ・イヤホンに依存します。Bluetoothのマイクは通話向けの音質になる場合があり、ブラウザから制御できない制約もあります。

音源・録音・歌詞は利用者のブラウザ内に保存されます。端末間のクラウド同期はありません。大切な制作物はバックアップしてください。

## 公開デモ

試し方：新しい曲を作成 → 「＋」からデモビートを追加 → 赤い録音ボタンで声を録音。録音時はマイク許可が必要です。操作だけなら、録音せずデモビートの再生・歌詞入力も試せます。

## 素材について

紹介画像の画面はアプリの実装をブラウザで表示したものです。表示データには、紹介のために生成したデモ波形とオリジナルのサンプル歌詞を使用しています。利用者の実際の録音・歌詞は含みません。スマートフォン枠は説明用のモックアップで、実機を撮影した写真ではありません。
