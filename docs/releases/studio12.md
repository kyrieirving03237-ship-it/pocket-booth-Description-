# STUDIO 12 — 録音直後の簡単なズレ調整

録音を停止すると「−10ms」「＋10ms」「リセット」「聴いて確認」が表示されます。ビートを再生しながら選んだ声だけ調整できます。手動補正は元の音声と別に保存し、WAVにも反映します。次回初期値は、希望したときだけその曲へ保存します。

更新前のサーバーソースとGit履歴は退避済みです。録音はサーバーではなく各端末内に保存されるため、サーバー公開時にiPhoneから取り出すことはできません。新版の初回起動では、編集前に既存の`projects`と旧` sessions`を別の端末内DB`pocket-booth-safety-backups`へコピーします。元DBは読み取り専用で扱い、削除・初期化・保存形式移行は行いません。コピー失敗時は通常の起動を止め、元データを変えずに案内します。

安全用コピーも同じSafariのサイトデータ内です。Safariのサイトデータを消すとコピーも失われます。大切な曲は既存の「プロジェクトをバックアップ」でファイルにも控えを残してください。更新は録音を止めてから行い、サイトデータの削除やホーム画面アプリの再インストールは不要です。

更新後にSTUDIO 12と表示されることを確認してください。iPhone実機の最終確認はユーザーが実施します。
