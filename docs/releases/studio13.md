# STUDIO 13 — タップで選択、録音開始時に遅延値を更新

クリップ／トラックをタップしても編集画面を自動表示せず、白い枠で選択します。上の「⋯」から編集画面を開けます。録音直後の簡単ズレ調整、長押し移動、拡大縮小は維持しています。

待機用マイクを準備した時の端末報告latencyを使い続けていたため、準備後に音声経路の報告値が変わると、古い値が録音配置へ使われていました。録音開始時に同じ報告値を再取得するよう修正しました。非同期の待ち時間、根拠のない固定補正、全トラックの一括補正は追加していません。

準備時30ms→録音時70msの模擬試験で、録音開始時の70msを使うことを確認しています。これがiPhoneでの−120ms／−80msの差の原因だったと確定したわけではありません。ブラウザが報告しない入力遅延や実機の変動は、PCだけでは測定できません。既存テイクの開始位置・手動補正・元音声は再計算しません。

今後の通常録音には、小さな補正情報を音声とは別に端末内へ保存します。編集メニューの「このテイクの録音情報」で、準備時と録音時の端末報告値を確認できます。取得できない値は取得不可と表示し、外部へ送信しません。ユーザーに長時間の校正やJSON提出を必須にはしません。

STUDIO 12のソース・履歴を公開前に退避。初回起動時の安全用コピーも13用に残し、12のコピーと元データは削除しません。

実機では、次回初期値を設定していた場合はいったん0msに戻し、短い声を2回録って比較してください。まだそれぞれ違う補正が必要なら、必要だった数値だけで構いません。完全な同期解決を確認するためには、少量の実機比較が必要です。
